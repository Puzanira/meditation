# Increment: Превью-стенд — все 4 сценки механик

Дата: 2026-07-29. Владелец: one-shot Opus owner (spec §2).

**Процессное решение founder (2026-07-29):** без микроинкрементов — проверки
редкие и пачками. Этот инкремент укрупнён: все 4 превью-сценки из
MECHANICS.md §7 в одной сборке, один плейтест-визит на всё. Внутри инкремента
до гейта 2 обязательны: машинный гейт (suite), Codex-скептик, дизайн-скептик

## 1. Пересказ дизайна

Собираем **превью-стенд**: одна Unity-сборка с меню из четырёх сценок, в
которых тюнятся все механики «Медитации в спешке» до постройки настоящих
уровней. Арт — прямоугольники-плейсхолдеры, раскладка экрана — по SCREENS.md,
поведение и порядок кадров — по gameplay-walkthrough.html (канонический
визуальный спек).

Сценки (порядок = порядок итераций из MECHANICS.md §7):

1. **«Динамо-сбор»** — одна деталь и сосуд, без мыслей. Непрерывное кручение
   динамо тянет деталь в сосуд; остановился — прогресс сбрасывается (или
   «тает» — тогглер).
2. **«Тряска-отгон»** — только мысли, без сбора. Тряска джойстика в любую
   сторону бьёт мысли; у мыслей разная прочность.
3. **«Две руки»** — сбор + волны мыслей вместе: конфликт внимания, ради
   которого игра и делается.
4. **«Уровень целиком»** — таймер, победа (все 5 деталей в сосуде),
   поражение (таймер истёк или мысли закрыли экран), передышки.

Каждый параметр [tune]/[toggle] из MECHANICS.md выведен на экранную панель
тогглеров/слайдеров: founder играет, крутит числа, находит «чувство»; финальные
значения после плейтеста записываются обратно в MECHANICS.md.

Управление: клавиатурная симуляция двух рук (общий модуль автомата; стрелки =
джойстик, отдельная клавиша/ось = динамо), при этом ввод идёт через нативный
ArcadeInput с первого дня (ARCADE_INTEGRATION_CONTRACT — новые игры без
миграционного долга). Кнопка «в меню» — мгновенный чистый выход из любой
сценки.

## 2. Done contract

1. **boots:** сборка стартует в меню превью-стенда без ошибок консоли; из меню
   открывается каждая из 4 сценок и возвращается в меню без перезапуска.
2. **player path (двуручная схема):** клавиатурная симуляция обеих рук работает
   во всех сценках: «кручение динамо» даёт непрерывный сбор, «тряска
   джойстика» даёт удары по мыслям.
3. **Сценка 1 «Динамо-сбор»:** деталь видимо едет в сосуд при непрерывном
   кручении; остановка дольше grace-периода роняет прогресс по выбранному
   режиму. Тогглеры: порог кручения, grace 0–800 мс, время сбора 3–15 с,
   сброс/таяние (A/B), влияние скорости кручения (A/B).
4. **Сценка 2 «Тряска-отгон»:** мысли появляются, тряска их выбивает по
   прочности типа. Тогглеры: порог детекта удара, прочности слабых/средних/
   крепких 2–12, затухание счётчика вкл/выкл + пауза 400–1500 мс,
   таргетинг A/B/C.
5. **Сценка 3 «Две руки»:** сбор и волны мыслей одновременно; бросил динамо
   ради тряски — деталь падает. Тогглеры: выбор детали A/B/C, интервал волн,
   дрейф мыслей вкл/выкл, порог поражения по перекрытию 85–100 %.
6. **Сценка 4 «Уровень целиком» + failure/restart:** таймер 60–180 с; победа
   при 5 деталях в сосуде до конца таймера; поражение при истёкшем таймере ИЛИ
   полном перекрытии экрана; после победы/поражения сценка перезапускается без
   выхода из сборки. Тогглеры: длительность уровня, передышка вкл/выкл + 0–5 с.
7. **Тогглеры (interaction path):** панель параметров видна на экране, меняет
   поведение сразу (без пересборки), значения не теряются при переключении
   сценок; после плейтеста финальные числа фиксируются в MECHANICS.md.
8. **observability:** раскладка экрана по SCREENS.md, элементы читаются как в
   gameplay-walkthrough.html (сосуд, деталь, мысли-прямоугольники, таймер);
   дизайн-скептик сверяет скрины со walkthrough покадрово.
9. **Платформенный контракт:** кнопка «в меню» из меню стенда и из любой
   сценки — мгновенный чистый выход (нативный ArcadeInput, без клавиатурных
   хаков в геймплейном коде).
10. **hygiene:** консоль без ошибок и missing references; suite GREEN
    (EditMode + PlayMode, PlayMode грузит реальные сцены стенда).
11. **regressions:** n/a — первый инкремент проекта, существующих игровых
    систем нет (голый шаблон URP 2D).
