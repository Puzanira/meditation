# Экраны и сцена — детальный спек (greybox)

Статус: черновик на утверждение founder'а. Арт — прямоугольники-плейсхолдеры,
но **раскладка, размеры и поведение — обязательные**: реализатор не изобретает
layout, а собирает по этому доку и мокапам:

- `docs/design/screens-mockup.html` — раскладки всех экранов и сцен уровней;
- `docs/design/gameplay-walkthrough.html` — покадровый разбор игрового цикла
  (12 шагов: взгляд → замечание → нить → тяга → мысль → тряска → срыв →
  добор), с состояниями рук (динамо/джойстик) на каждом шаге.

Разрешение экрана стойки: **1920×1080** (подтверждено founder'ом 2026-07-29).
Все координаты в px от левого-верхнего угла, без масштабирования.

**Источник композиций сцен — раскадровки founder'а**
`docs/files (1)/Uroven_1_l1_raskadrovka.png … Uroven_5_l5_raskadrovka.png`.
Кадры 1–6 каждой раскадровки соответствуют состояниям уровня: обзор (intro) →
перетаскивание (play) → первая мысль → пик хаоса (peak) → отгон → финал (win).
Координаты ниже — перенос раскадровок на сетку 1920×1080, допуск ±50 px.

Поток экранов:

```
Лаунчер (удержание джойстика)
  → S1 Титул → S2 Карточка уровня → S3 Уровень (L1 = с обучением)
       S3 победа → S4 Победа уровня → S2 следующего уровня … → S6 Финал → лаунчер
       S3 поражение → S5 Поражение → рестарт того же S3
Кнопка «в меню» из ЛЮБОГО экрана → мгновенный чистый выход (контракт стойки).
```

## S3. Экран уровня — главный (описан первым, он определяет всё)

### Зоны (постоянная раскладка, все уровни)

| Зона | Прямоугольник (x, y, w, h) | Что в ней |
|------|---------------------------|-----------|
| Сцена | 0, 0, 1920, 810 | фон локации + 5 деталей на авторских позициях |
| Полоса переднего плана | 0, 810, 1920, 270 | земля/пол, на ней сосуд |
| Сосуд | центр (960, 930), габарит 240×150 | цель сбора; собранные детали видны внутри |
| HUD: слоты деталей | от (60, 40): 5 слотов 72×72, шаг 88 | силуэты деталей уровня; собранная — заполняется |
| HUD: таймер | круг, центр (1800, 100), r=60 | «солнце»-циферблат: сектор убывает по часовой |
| HUD: индикатор динамо | круг, центр (140, 950), r=70 | стрелка скорости кручения; зелёная дуга = «достаточно» |
| Слой мыслей | поверх сцены и деталей | мысли закрывают обзор; HUD они не закрывают |

Z-порядок (снизу вверх): фон сцены → детали → нить сбора → слой мыслей →
полоса переднего плана и сосуд *(закрывается ли сосуд мыслями — [toggle],
MECHANICS §4)* → HUD.

### Детали в сцене

- Габарит детали: 40–90 px по большей стороне (мелкая, «интересная»).
- Позиции авторские, на уровень фиксированы. Уровень 1 (по раскадровке):

| Деталь | Позиция (центр) |
|--------|-----------------|
| Одуванчик в трещине | (180, 760) — у подножия 1-го небоскрёба |
| Отражение облака | (560, 330) — верх стекла 2-го небоскрёба |
| Кофейная чашка на парапете | (1000, 700) |
| Воробей на проводе | (1330, 300) |
| Тень от вывески | (1650, 740) |

  Композиции сцен и позиции деталей всех уровней — раздел «Сцены уровней 1–5»
  ниже.

- Незамеченная деталь слегка пульсирует: масштаб 1.0→1.12, цикл 1.6 с
  *(заметность пульса **[tune]** — на поздних уровнях слабее)*.

### Выбор детали («заметить») — конкретный дизайн вариантов [toggle]

Базовый вариант — **B (взгляд джойстиком)**, A и C остаются тогглерами:

- **B. Взгляд джойстиком (базовый).** Плавный наклон стика двигает по сцене
  мягкий круг-«взгляд» r=90 px, скорость 900 px/с **[tune]**. Взгляд держится
  на детали 0.4 с **[tune]** → деталь «замечена»: вспышка + от детали к сосуду
  протягивается пунктирная нить. Дальше сбор ведёт динамо, взгляд не нужен.
  Разводка жестов одного стика: плавный наклон = взгляд; резкие смены
  направления (детект удара, MECHANICS §3) = тряска. Во время тряски взгляд
  замирает на месте.
- **A. Фиксированный порядок.** Взгляда нет; текущая цель подсвечена пульсом,
  кручение тянет её. Порядок авторский (от заметной к спрятанной).
- **C. Автовыбор.** Кручение тянет ближайшую к сосуду деталь, не закрытую
  мыслями.

### Сбор (визуал состояния)

- Замеченная деталь едет к сосуду по нити со скоростью = прогресс кручения;
  путь = прямая деталь→сосуд.
- Вокруг едущей детали — **кольцо прогресса**: заполняется по мере пути;
  пока динамо крутится выше порога — кольцо зелёное; кручение упало — кольцо
  краснеет, и через grace-период деталь «срывается»: летит обратно на своё
  место (0.6 с), кольцо гаснет (или тает — режим B, MECHANICS §1).
- Индикатор динамо (HUD слева-внизу) дублирует состояние: стрелка в зелёной
  дуге = хватает, вышла — красная подсветка + вибрация иконки.
- Деталь дошла до сосуда: подпрыгивание сосуда (scale 1.0→1.1→1.0, 0.3 с),
  деталь появляется внутри сосуда, слот в HUD заполняется.

### Мысли (визуал состояния)

- Габариты: S 180×140, M 280×220, L 420×320 px (скруглённые прямоугольники-
  плейсхолдеры с подписью типа мысли).
- Спавн: выплывают из-за краёв экрана (случайная сторона), дрейф к центру
  20–60 px/с **[tune]**; перекрываются.
- Прочность: под мыслью ряд точек-пипсов (= числу оставшихся ударов).
  Удар тряски: мысль вздрагивает (±6 px, 80 мс), пипс гаснет. Последний пипс —
  мысль лопается (масштаб 1.1 → 0, 200 мс).
- Пик хаоса: при перекрытии ≥ порога **[tune]** — лёгкое затемнение краёв
  экрана + учащение «сердцебиения» фона (см. Audio, позже).

### Состояния S3 (машина состояний уровня)

1. `intro` (2 с): сцена без мыслей, все 5 деталей пульсируют разом — «обзор».
2. `play`: основной цикл (MECHANICS §1–5). Таймер идёт.
3. `peak`: перекрытие ≥ порога — визуал пика хаоса (не отдельная логика).
4. `win` → S4; `lose` → S5.

### Обучение (только уровень 1, скриптовые биты внутри `play`)

1. Мысли не спавнятся. Стрелка + текст у первой детали: «Крути ручку —
   собери одуванчик». Таймер стоит.
2. Первая деталь в сосуде → спавнится первая мысль (гора посуды), сбор
   заблокирован её появлением поверх следующей детали. Текст: «Тряси
   джойстик — отгони мысль!»
3. Мысль отбита → таймер запускается, дальше обычный `play`.
   *(Таймер в обучении стоит — [toggle: да/нет].)*

## S1. Титул

- Фон: сцена уровня 1 без деталей, по ней медленно дрейфуют 3–4 мысли.
- Название «МЕДИТАЦИЯ В СПЕШКЕ»: центр (960, 300), кегль ~120.
- Две карточки-пиктограммы 360×240, y=520: левая (740) «КРУТИ — собирай
  детали» (иконка ручки), правая (1180) «ТРЯСИ — отгоняй мысли» (иконка
  джойстика с линиями тряски).
- Низ (960, 900): «Крути ручку, чтобы начать» — старт по 2 оборотам динамо
  *(тематично: игра начинается с медленного кручения)*.

## S2. Карточка уровня (интерстишл, 2.5 с, авто)

- Тёмный фон; центр: «Уровень N — <название>» (960, 460, кегль 72);
  под ним силуэт сосуда уровня (960, 620) и 5 пустых слотов деталей.

## S4. Победа уровня (3 с, авто → S2 следующего)

- Мысли растворяются (0.5 с), сцена чистая 1 с — «тишина».
- Сосуд плавно в центр (960, 540), масштаб ×2, в нём все 5 деталей.
- Текст под сосудом: «Собрано: <сеттинг>» + заполненные слоты.

## S5. Поражение

- Экран целиком закрыт мыслями, лёгкая десатурация.
- Центр (960, 480): «Мысли захватили всё. Вдохни.»
- Ниже (960, 620): «Крути ручку — попробуй снова»: каждый оборот динамо
  стирает ~10 % мыслей с экрана; очистил — рестарт уровня (S2 того же уровня).
  *(Ретрай тоже медитативен — предложение, [toggle: авто-ретрай через 4 с].)*

## S6. Финал (после уровня 5)

- Все 5 сосудов в ряд по центру (шаг 340, y=540), каждый со своими деталями.
- Текст (960, 300): «Ты заметил(а) всё. Даже в спешке.»
- Через 20 с бездействия или по любому вводу — чистый выход в лаунчер.

## Общие правила

- Переходы между экранами: фейд в чёрный 0.3 с.
- Кнопка «в меню»: из любого состояния — мгновенный чистый выход (контракт).
- Бездействие (нет ввода) 60 с на любом экране кроме S3 → выход в лаунчер
  **[открытый вопрос: есть ли общий idle-контракт стойки?]**
- Всё текстовое — русский; текст крупный (музейная дистанция ~1 м).
