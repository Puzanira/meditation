# Бриф автомата (контекст для дизайн-сессии)

Игра — одна из 7 на реальном физическом аркадном автомате (музейная стойка,
один ПК/экран, у игрока НЕТ клавиатуры/мыши). Пульт: крутилка-динамо, красная
кнопка, зелёная кнопка, кнопка «!», два датчика высоты, джойстик, служебная
кнопка «в меню».

**Слот этой игры: ДЖОЙСТИК** — запуск удержанием джойстика в лаунчере; джойстик
же — основное игровое управление (другие контролы пульта можно задействовать
дополнительно). Контракты: по кнопке «в меню» игра чисто завершается; никакого
текстового ввода/мыши. До железа — клавиатурная симуляция (готовый модуль
arcade-controls, дизайну не важна). Дизайнить под ФИЗИЧЕСКИЙ джойстик.

Полная спека автомата (только если реально нужно): system/specs/ARCADE_CABINET_SPEC.md
