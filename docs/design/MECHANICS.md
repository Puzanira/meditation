# Механики — детальный спек

Статус: **черновик для итераций через превью-сценки.**
Процесс: структурные правила фиксируются здесь; всё помеченное **[tune]**
(число, диапазон) и **[toggle]** (переключаемый вариант) выносится реализатором
в превью-сценку тогглером/слайдером — founder играет и докручивает. Итоговые
значения после плейтеста записываются обратно в этот док.

Арт: пока прямоугольники-плейсхолдеры (см. WORLD.md). Управление: двуручная
схема — динамо (сбор) + джойстик (отгон); клавиатурная симуляция — готовый общий
модуль, здесь не описывается.

---

## 1. Сбор (динамо, «медленная линия»)

Правила (решено, из описания):
- Непрерывное вращение динамо тянет замеченную деталь в сосуд.
- Прогресс держится только пока рука крутит без остановки; бросил — деталь
  падает, тащить заново.

Параметры:
- Порог «кручения»: минимальная скорость вращения, ниже — «остановился»
  **[tune]**
- Grace-период: сколько прощаем при заминке до сброса **[tune: 0–800 мс]**
- Поведение при остановке **[toggle]**:
  - A. прогресс сбрасывается в ноль (как в описании);
  - B. прогресс быстро «тает» — успел вернуться к кручению, часть спас.
- Время сбора одной детали при нормальном кручении **[tune: 3–15 с]**
- Влияет ли скорость кручения на скорость сбора **[toggle]**:
  - A. нет — важна только непрерывность (медитативнее);
  - B. да, до потолка (аркаднее, но провоцирует «крутить бешено»).

## 2. Выбор детали («заметить»)

> Открыто — решаем плейтестом. Варианты **[toggle]**:
- A. Фиксированный порядок: детали подсвечиваются по одной, кручение тянет
  текущую. Просто, но «замечание» теряется.
- B. Наведение джойстиком: наклоном выбираешь деталь, кручением тянешь. Даёт
  настоящее «оглядывание», но джойстик конфликтует с тряской — возможно, это
  интересное напряжение.
- C. Автовыбор ближайшей видимой (не закрытой мыслями) детали.

## 3. Отгон мыслей (джойстик, «быстрая линия»)

Правила (решено, из описания):
- Тряска в любую сторону; направление не важно, важна частота.
- У каждой мысли своя прочность — число ударов до исчезновения.

Параметры:
- Детект «удара»: смена направления наклона с амплитудой выше порога
  **[tune]**
- Прочность мыслей по типам: слабые/средние/крепкие **[tune: 2–12 ударов]**
- Затухание счётчика ударов **[toggle]**: если пауза между ударами > X мс —
  счётчик мысли сбрасывается / не сбрасывается; X **[tune: 400–1500 мс]**
- Таргетинг ударов **[toggle]**:
  - A. удары идут по всем мыслям на экране сразу (тряска «сдувает» всё);
  - B. по одной — ближайшей к центру / самой свежей;
  - C. по той, на которую наклонён стик (конфликтует с вариантом 2B).

## 4. Мысли: волны и перекрытие экрана

Правила (решено, из описания):
- Мысли наступают волнами, накладываются друг на друга.
- Чем дольше медлишь, тем больше их скапливается — закрывают обзор на сеттинг.
- Если мысли полностью заполняют экран и не успеваешь разгрести — game over.

Параметры:
- Интервал между волнами **[tune per level]**
- Состав волны: сколько и каких мыслей **[tune per level]**
- Рост давления внутри уровня (интервалы сокращаются?) **[toggle: да/нет]**
- Движутся ли мысли по экрану **[toggle]**: статичны / медленно дрейфуют к
  центру (наступают)
- Порог поражения по перекрытию: % закрытой площади экрана
  **[tune: 85–100 %]**
- Где могут появляться мысли: могут ли закрывать сосуд и деталь, которую
  сейчас тянешь **[toggle: да/нет]**

## 5. Таймер, победа, поражение

Правила (решено, из описания):
- На уровень отведён таймер («спешка» реальной жизни).
- Победа: все 5 деталей в сосуде до истечения времени.
- Поражение: истёк таймер ИЛИ мысли заполнили экран.

Параметры:
- Длительность уровня **[tune per level: 60–180 с]**
- Пауза-передышка после каждой собранной детали (мысли не спавнятся X с)
  **[toggle: есть/нет]**, X **[tune: 0–5 с]**

## 6. Прогрессия сложности (5 уровней)

Из описания: с каждым уровнем больше мыслей, выше прочность, быстрее наплыв,
детали мельче и спрятаннее. Конкретная таблица чисел по уровням заполняется
после того, как база оттюнена на уровне 1.

## 7. Заказ превью-сценок реализатору (порядок итераций)

1. **«Динамо-сбор»** — сцена с одной деталью и сосудом, без мыслей.
   Тогглеры: порог кручения, grace, время сбора, сброс/таяние прогресса,
   влияние скорости.
2. **«Тряска-отгон»** — только мысли, без сбора.
   Тогглеры: детект удара, прочности, затухание счётчика, таргетинг A/B/C.
3. **«Две руки»** — сбор + волны мыслей вместе.
   Тогглеры: вариант выбора детали A/B/C, интервалы волн, дрейф мыслей,
   порог перекрытия.
4. **«Уровень целиком»** — таймер, победа/поражение, передышки.

Платформенный контракт во всех сценках: кнопка «в меню» — мгновенный чистый
выход.
